# NumPy Basic Data Analysis

## About the Project
This is my beginner Python project using NumPy. I created it while learning how to work with numerical data and perform basic data analysis using Python.

## Features
- Store marks using NumPy arrays
- Calculate average marks
- Find maximum and minimum values
- Filter passing and failing marks
- Identify students scoring 80 or above
- Perform basic statistical calculations

## Technologies Used
- Python
- NumPy

## Learning Outcomes
- Understanding NumPy arrays
- Array filtering and conditions
- Basic statistics using NumPy
- Data analysis fundamentals

## How to Run
1. Install Python.
2. Install NumPy using:
   `pip install numpy`
3. Run the Python file.
